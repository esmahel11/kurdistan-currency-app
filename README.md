# 🏦 سیستەمی نرخی دراو و زێڕ

وێب ئەپێکی تەواو بۆ نیشاندانی نرخی دراو و زێڕ بە سکراپینگی ئۆتۆماتیک لە Rudaw Index.

## 🌟 تایبەتمەندییەکان

### 💰 نرخی دراو (کڕین و فرۆشتن)
- دۆلار ئەمریکی
- یۆرۆ
- پاوەندی ئینگلیزی
- تمەنی ئێرانی
- لیرەی تورکی
- ڕیاڵی سعوودی
- درهەمی ئیماراتی
- دیناری ئوردنی

### 🥇 نرخی زێڕ
- نرخی فەرمی سەندیکا (عەیار ١٨، ٢١، ٢٢)
- نرخی کڕینەوە بۆ هاووڵاتی
- نرخی لیرەی زێڕ

### 🔧 تایبەتمەندییە تایبەتەکان
- 💱 گۆڕینەوەی دراو (هەموو دراوەکان)
- 🚗 خەمڵێنەری گومرگی ئۆتۆمبێل (کوردستان و عێراق)
- 🕌 هەژمارکەری زەکات (پارە، کشتوکاڵ)
- 🔄 نوێکردنەوەی ئۆتۆماتیک
- 🎨 دیزاینی شاهانە
- 📱 **گونجاو لەگەڵ مۆبایل و تابلێت**

## 📱 پشتگیری مۆبایل

ئەم وێب ئەپە بە تەواوی گونجاوە لەگەڵ:

- ✅ تابلێتی گەورە (769px - 1024px)

بۆ زانیاری زیاتر، سەیری [README-MOBILE.md](README-MOBILE.md) بکە.

## 🚀 چۆنیەتی بەکارهێنان

### دامەزراندن

```bash
npm install
```

### دەستپێکردن

```bash
npm start
```

سێرڤەرەکە لەسەر `http://localhost:3000` دەستپێدەکات.

## ⚙️ چۆنیەتی کارکردن

### سکراپینگی ئۆتۆماتیک

سێرڤەرەکە **هەر ٣٠ خولەک** بە ئۆتۆماتیک نرخەکان لە Rudaw Index وەردەگرێت:

1. چوونە سەر `https://rudawindex.net`
2. کلیککردن لەسەر "کانزاکان (کوردستان)" بۆ نرخی زێڕ
3. کلیککردن لەسەر "دراوەکان" بۆ نرخی دراو
4. پاشەکەوتکردنی نرخەکان لە `current-prices.json`

### نوێکردنەوەی وێب ئەپ

وێب ئەپەکە **هەر ٥ خولەک** نرخەکان لە سێرڤەر وەردەگرێت بە ئۆتۆماتیک.

### نوێکردنەوەی دەستی

دەتوانیت بە دەستی نرخەکان نوێ بکەیتەوە:

```bash
# لە وێبگەڕ
http://localhost:3000/api/refresh

# یان لە تێرمیناڵ
node rudaw-scraper.js
```

## 🔄 کاتی نوێکردنەوە

- **سێرڤەر (سکراپینگ)**: هەر ٣٠ خولەک
- **وێب ئەپ (نیشاندان)**: هەر ٥ خولەک
- **نیشانەکانی رەنگ**: هەر ١٠ چرکە

## 🛠️ تێکنەلۆژیەکان

- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Node.js, Express
- **Scraping**: Puppeteer
- **Data Source**: Rudaw Index (https://rudawindex.net)

## 📝 تێبینیەکان

- نرخەکان لە Rudaw Index وەردەگیرێن (سەرچاوەی فەرمی)
- سیستەمەکە بە تەواوی ئۆتۆماتیکە
- نرخەکان لە `current-prices.json` پاشەکەوت دەکرێن
- وێب ئەپەکە بە شێوەیەکی ڕاستەوخۆ نرخەکان نوێ دەکاتەوە

## 🎯 بەکارهێنان

### لە کۆمپیوتەر
1. سێرڤەرەکە دەستپێبکە: `npm start`
2. وێبگەڕەکە بکەرەوە: `http://localhost:3000`
3. نرخەکان بە ئۆتۆماتیک نوێ دەبنەوە!

### لە مۆبایل
1. دڵنیابە سێرڤەرەکە کاردەکات
2. لە مۆبایلەکەت بڕۆ بۆ: `http://[IP-ی-کۆمپیوتەرەکەت]:3000`
3. وێب ئەپەکە بە تەواوی گونجاوە لەگەڵ مۆبایل!

**تێبینی**: بۆ بەکارهێنانی لە مۆبایل، دڵنیابە کۆمپیوتەر و مۆبایلەکەت لە هەمان نێتوۆرکدان.

# ڕێنمایی بەکارهێنانی مۆبایل

## تایبەتمەندییەکانی دۆخی مۆبایل

### ١. دیزاینی گونجاو (Responsive Design)
- **مۆبایلی بچووک** (< 480px): دیزاینێکی تەواو گونجاو بۆ مۆبایلەکانی بچووک
- **تابلێت** (481px - 768px): دیزاینێکی ناوەڕاست بۆ تابلێتەکان
- **تابلێتی گەورە** (769px - 1024px): دوو ستوون بۆ بینینی باشتر
- **دۆخی Landscape**: دیزاینێکی تایبەت بۆ دۆخی ئاسۆیی

### ٢. باشکردنەکانی مۆبایل

#### قەبارەی فۆنت
- سەرناو: کەمکراوەتەوە بۆ ١.٤em لە مۆبایلی بچووک
- ناوی دراو: ٠.٨٥em بۆ خوێندنەوەی ئاسان
- نرخەکان: ٠.٨٥em بۆ نیشاندانی باشتر

#### دوگمەکان
- قەبارەی کەمینە: ٤٤px بۆ لامسانی ئاسان
- touch-action: manipulation بۆ وەڵامدانەوەی خێرا
- -webkit-tap-highlight-color: transparent بۆ لابردنی ڕەنگی لامسان

#### Input و Select
- قەبارەی گونجاو: ١١px padding لە مۆبایلی بچووک
- -webkit-appearance: none بۆ دیزاینی یەکگرتوو
- touch-action: manipulation بۆ کارکردنی باشتر

#### کارتەکان
- padding کەمکراوە: ١٥px لە مۆبایلی بچووک
- border-radius: ١٢px بۆ دیزاینی نەرم
- gap کەمکراوە: ١٢px لە نێوان کارتەکان

### ٣. نیشاندانی نرخەکان

#### نرخی کڕین و فرۆشتن
- لە مۆبایل: دوو ڕیز (ستوونی)
- لە تابلێت: دوو ڕیز (ستوونی)
- ڕەنگی جیاواز: سەوز بۆ کڕین، سوور بۆ فرۆشتن

#### نیشانەکان (Indicators)
- قەبارە: ١٠px لە مۆبایلی بچووک
- ئەنیمەیشن: گونجاو لەگەڵ هەموو قەبارەکان

### ٤. خشتەکان

#### خشتەی گومرگ
- قەبارەی فۆنت: ٠.٨٥em لە مۆبایل
- padding: ٨px بۆ خانەکان
- scroll ئاسۆیی ئەگەر پێویست بوو

### ٥. تێبینییەکان و زانیاری

#### بەشە زانیارییەکان
- قەبارەی فۆنت: ٠.٨em لە مۆبایل
- padding: ١٠px
- line-height: ١.٦ بۆ خوێندنەوەی ئاسان

#### لیستەکان
- margin: ١٥px لە لای ڕاست
- line-height: ١.٦
- gap: ٤px لە نێوان ئایتمەکان

## چۆنیەتی تاقیکردنەوە

### ١. لە کۆمپیوتەر
1. کردنەوەی Chrome DevTools (F12)
2. کرتەکردن لەسەر ئایکۆنی مۆبایل (Ctrl+Shift+M)
3. هەڵبژاردنی جۆری مۆبایل:
   - iPhone SE (375x667)
   - iPhone 12 Pro (390x844)
   - Samsung Galaxy S20 (360x800)
   - iPad (768x1024)

### ٢. لە مۆبایلی ڕاستەقینە
1. کردنەوەی `currency-app.html` لە بڕاوزەری مۆبایل
2. تاقیکردنەوەی هەموو تایبەتمەندییەکان:
   - گۆڕینەوەی دراو
   - هەژماری گومرگ
   - هەژماری زەکات
   - نوێکردنەوەی نرخەکان

### ٣. تاقیکردنەوەی دۆخی Landscape
1. سووڕاندنەوەی مۆبایل بۆ دۆخی ئاسۆیی
2. پشتڕاستکردنەوەی دیزاین بە دوو ستوون

## تێبینییەکانی گەشەپێدەر

### Media Queries بەکارهاتوو
```css
@media (max-width: 768px) { /* تابلێت */ }
@media (max-width: 480px) { /* مۆبایلی بچووک */ }
@media (max-width: 896px) and (orientation: landscape) { /* Landscape */ }
@media (min-width: 769px) and (max-width: 1024px) { /* تابلێتی گەورە */ }
```

### تایبەتمەندییەکانی CSS بەکارهاتوو
- `touch-action: manipulation` - بۆ لامسانی باشتر
- `-webkit-tap-highlight-color: transparent` - لابردنی ڕەنگی لامسان
- `-webkit-appearance: none` - دیزاینی یەکگرتوو
- `backdrop-filter: blur()` - کاریگەری شووشە
- `flex-direction: column` - نیشاندانی ستوونی

### Viewport Settings
```html
<meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=5.0, user-scalable=yes">
```
